Conectar ao GitHub

Para criar e editar projetos, o site precisa de uma chave que só você tem. Ela fica guardada neste navegador e nunca vai para o código do site.

  1. GitHub → foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque youtubevideosgba.
  3. Em Permissions → Repository permissions, coloque Contents: Read and write e também Actions: Read and write (esta serve para o botão “Atualizar agora” do dashboard).
  4. Gere, copie o código e cole abaixo.
